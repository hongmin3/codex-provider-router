# Troubleshooting

## Diagnosis rule
<!-- akela: id=diagnosis scope=develop,test,operate tier=should -->
오류 메시지, 재현 조건, 관련 로그의 최소 범위를 확인하고 근거 없이 외부 API나 selector 변경을 추측하지 않습니다.

## Secret handling
<!-- akela: id=secrets scope=all tier=must -->
API key, token, cookie, credential, 개인정보를 Knowledge, Evidence, 로그, 저장소에 복사하지 않습니다.
